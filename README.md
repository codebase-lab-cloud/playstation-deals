# PS Deals — Pay & Play Full Games Tracker

## Purpose
PS Deals tracks discounted and free PlayStation 4 & PlayStation 5 full games in real-time, focusing specifically on complete titles without clutter from DLCs or cosmetic packs.

## Tech Stack
- **Frontend**: HTML5, Vanilla JavaScript (ES6+)
- **Styling**: Tailwind CSS, Google Fonts (Space Grotesk & JetBrains Mono)
- **Data Source**: PlayStation Store Chihiro Public API (India & US regions)
- **Architecture**: Progressive Web App (PWA) with Service Worker caching

## About
Features live price validation directly against the official PlayStation Store API, instant price conversion to INR, quick store links, and an interactive game search tool for checking live pricing and availability.
