## Permanent Free Hosting (30 sec):

### 1. Netlify Drop - Easiest
1. Open https://app.netlify.com/drop
2. Drag `index.html` into the page
3. You get permanent URL like https://ps-deals-india-xxx.netlify.app
4. Works on any phone forever

### 2. Tiiny.host
1. Go to https://tiiny.host
2. Upload index.html
3. Get URL like https://ps-deals.tiiny.site

### 3. GitHub Pages
1. Create repo `ps-deals` on github.com
2. Upload index.html as `index.html`
3. Settings > Pages > Deploy from main branch
4. URL: https://yourusername.github.io/ps-deals/

All options serve the same single HTML file - no build needed.
